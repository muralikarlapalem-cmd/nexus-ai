What talks to what

  • The browser signs in at Keycloak (PKCE) and calls the API with that token.
  • The API answers at once; agent work goes to Celery through Redis.
  • The LangGraph supervisor runs Triage → Security? → Diagnosis → Knowledge inside the worker, checkpointed in Redis.
  • Agents search the knowledge base through the in-process RAG library (Qdrant + BM25 + reranker) and call OpenAI.
  • The worker imports incidents from ServiceNow and posts results back as work notes.

Safeguards

  • Injection guard on every text input; Presidio removes personal data before storage and LLM calls.
  • Lost connection: retries after 1, 2, 4 min; dead runs handed to a person.
  • One run per ticket; one sync per connection; no duplicate imports or notes.

NEXUS AI · Agents, RAG and Integrations

How a ticket moves through the agents, how the knowledge base is queried and fed,
and how ServiceNow incidents come in and go back

A. Ticket flow through the LangGraph supervisor

Triggered by POST /agents/run/{id}, by an imported ticket, or by Retry agents. *Triage escalates on data-loss risk, an outage over 1 h, a security breach, or confidence below 0.4. The Security agent also reads the last hour of NEXUS logs from Loki.

B. RAG query path

Query/rag/query, /rag/query/stream or the rag_search tool; personal data redacted
→
Embedsame model as ingestion
→
RetrieveQdrant top 10 (tenant, type, category filters) + BM25 top 10
→
RRF fusescore = Σ 1/(60 + rank); keep 20
→
Rerankcross-encoder scores each (query, chunk) pair; keep 3
→
Generatecontext-only prompt with numbered, cited sources

C. Knowledge-base ingestion path

Sourcessample runbooks, raw text, PDF / Markdown uploads, resolved tickets, agent runbooks
→
Load + redactdocuments + metadata; personal data removed (Presidio)
→
Chunk512 tokens, 64 overlap; header-aware; drops chunks under 50
→
EmbedOpenAI 1536-d or Ollama 768-d
→
IndexQdrant upsert with deterministic chunk IDs; BM25 add

D. ServiceNow (or any connected system)

ServiceNowincident created, state New
→
SyncBeat checks every minute; each connection syncs on its own interval, or at once by webhook
→
Saveone NEXUS ticket per incident, personal data redacted, unchanged ones skipped
→
Agentsrun once, only for tickets that arrive open
→
Write backdiagnosis and steps posted as an internal work note, never twice
